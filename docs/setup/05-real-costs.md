## ২. কিন্তু ফ্রি টিয়ারে আসল সাইট চলবে না — দুটো কারণ

### ⚠️ কারণ ১: 10 ms CPU limit (সবচেয়ে বাজে ফাঁদ)

Workers ফ্রি প্ল্যানে **প্রতি রিকোয়েস্টে মাত্র ১০ মিলিসেকেন্ড CPU**।

Next.js SSR — React রেন্ডার, ডেটাবেস কুয়েরি, টেমপ্লেট — এটা অনায়াসে ১০ ms
পেরিয়ে যায়। আর সবচেয়ে খারাপ দিক: সবসময় পরিষ্কার এরর দেয় না, কখনো কখনো
অর্ধেক রেসপন্স ফেরত আসে বা `1101` এরর দেখায়।

Workers Paid-এ এটা **৩০ সেকেন্ড** (ডিফল্ট)। পার্থক্য ৩০০০ গুণ।

> **এই একটা কারণেই $5/মাস লাগবে।** কোড অপ্টিমাইজ করে এড়ানো যাবে না।

### ⚠️ কারণ ২: R2 চালু করতেই কার্ড লাগে

R2-এর ফ্রি টিয়ার আছে (১০ GB), কিন্তু **সার্ভিসটা enable করতেই Cloudflare
পেমেন্ট মেথড চায়** — ফ্রি টিয়ারের জন্যও। R2 একটা usage-based প্রোডাক্ট,
"ফ্রি প্ল্যান" না।

ভিডিও ছাড়া টিউব সাইট হয় না, R2 ছাড়া ভিডিও রাখা যায় না। তাই কার্ড বাধ্যতামূলক।

## ৩. খরচের উপাদানগুলো

অন্তর্ভুক্ত: ১ কোটি রিকোয়েস্ট/মাস, ৩ কোটি CPU-ms/মাস।
তার বেশি: +$0.30/মিলিয়ন রিকোয়েস্ট, +$0.02/মিলিয়ন CPU-ms।

বেশিরভাগ ছোট-মাঝারি সাইট $5-এর ভেতরেই থাকে।

### 🔍 লুকানো খরচ: Class B operations (HLS-এর কারণে)

এটা প্রায় সবাই মিস করে।

HLS স্ট্রিমিং ভিডিওকে ~৬ সেকেন্ডের সেগমেন্টে ভাগ করে। **প্রতিটা সেগমেন্ট
ডাউনলোড = একটা আলাদা Class B operation।**

```
১০ মিনিটের ভিডিও  = ~১০০ সেগমেন্ট
১ জন পুরো দেখলে   = ~১০০ Class B ops
ফ্রি ১০M ops/মাস   = ~১,০০,০০০ সম্পূর্ণ ভিউ/মাস
```

তার বেশি: $0.36/মিলিয়ন ops। ১০ লাখ ভিউ/মাস হলে ~১০ কোটি ops = **~$32/মাস**।

> **অপ্টিমাইজেশন:** সেগমেন্ট ৬ সেকেন্ডের বদলে ১০ সেকেন্ড করলে ops প্রায়
> ৪০% কমে যায়। শুরু থেকেই এটা সেট করে রাখব।

### 🔍 লুকানো খরচ: ভিডিও ট্রান্সকোডিং

**এটাই সবচেয়ে বড় ভুলে যাওয়া খরচ।**

আপলোড করা MP4-কে HLS-এ রূপান্তর করতে ffmpeg লাগে। **ffmpeg Workers-এ চলবে না** —
১২৮ MB মেমরি, কোনো ফাইলসিস্টেম নেই, CPU লিমিট আছে। বিকল্প তিনটা:

| উপায় | খরচ | মন্তব্য |
|---|---|---|
| **নিজের PC-তে** ffmpeg চালিয়ে R2-তে আপলোড | **$0** | ম্যানুয়াল, কিন্তু শুরুতে একদম ঠিক আছে |
| **VPS** (Hetzner/Contabo) + ffmpeg worker | $5–10/মা | অটোমেটেড, স্কেলেবল — আসল সমাধান |
| **Cloudflare Stream** | $5/১০০০ মিনিট সংরক্ষণ + $1/১০০০ মিনিট ডেলিভারি | টিউব স্কেলে খুব দামি |

> Stream-এ ১০,০০০ ভিডিও × ১০ মিনিট = ১,০০,০০০ মিনিট = **$500/মাস শুধু স্টোরেজে**।
> R2 + নিজের ট্রান্সকোডিং-এ সেটাই ~$45। **Stream ব্যবহার করব না।**

### Image optimization — $0 (যদি ঠিকভাবে করি)

OpenNext-এর `next/image` অপ্টিমাইজেশন Cloudflare Images চায়, যেটা ফ্রি না।

**আমরা এড়াব:** থাম্বনেইল আগেই দুই সাইজে বানিয়ে R2-তে রাখব
(`360x203`, `240x135` — letsporn যেমন করে)। রানটাইমে কোনো রিসাইজ লাগবে না,
তাই Cloudflare Images-ও লাগবে না। **$0।**

### D1 — কার্যত $0

ফ্রি: ৫ GB, ৫M rows read/দিন, ১,০০,০০০ rows written/দিন।
Workers Paid নিলে এমনিতেই অনেক বেশি পাওয়া যায়। মেটাডেটা এত ছোট যে এটা
কখনোই বিলের বড় অংশ হবে না।

⚠️ কিন্তু "rows read" মানে কুয়েরি **যত রো স্ক্যান করে** তত — রিকোয়েস্ট সংখ্যা না।
index ছাড়া একটা SELECT দিনের কোটা খেয়ে ফেলতে পারে। **প্রতিটা ফিল্টার কলামে
index দিতেই হবে।**

## ৫. খরচ কমানোর কৌশল

1. **HLS সেগমেন্ট ১০ সেকেন্ড** (৬ নয়) → Class B ops ~৪০% কম
2. **থাম্বনেইল আগেই রিসাইজ** করে R2-তে → Cloudflare Images লাগবে না
3. **ISR/ক্যাশিং আক্রমণাত্মকভাবে** → Worker CPU-ms কমে
4. **ভিউ কাউন্টার KV বা Durable Object-এ**, D1-এ না → রাইট কোটা বাঁচে
5. **পুরনো/কম দেখা ভিডিও R2 Infrequent Access-এ** → $0.01/GB (৩৩% সাশ্রয়)
6. **Cloudflare Stream এড়িয়ে চলুন** — টিউব স্কেলে ১০ গুণ দামি
7. **প্রতিটা ফিল্টার কলামে D1 index** → rows-read কোটা বাঁচে
